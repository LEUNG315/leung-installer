## 当前不应过度承诺的内容

在真实兼容性验证完成前，不应对外绝对承诺：
- 所有主流 Linux 发行版均已验证
- 所有包管理器路径都已在线上环境跑通
- 所有 CLI 都在每种架构上完成真实安装

## 发布前建议最小实测矩阵

至少记录以下组合：

1. Ubuntu latest + `x86_64`
2. Debian stable + `x86_64`
3. Fedora latest + `x86_64`
4. Ubuntu/Debian ARM64 + `aarch64`（如对外声明支持）

每个组合至少验证：
- 非交互安装
- 配置写入
- CLI 二进制存在
- 最小可用命令
- 连通性检查
